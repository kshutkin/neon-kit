Multicombobox — Web Component

<neon-multicombobox> is a Light-DOM, form-associated custom element that wraps the theme's .combobox.-multi markup with a multi-select, filterable, keyboard-friendly popover. List options as plain <option> children — selected items render as .tag chips inside the field, and the popover lists each option as a <label> wrapping a real <input type="checkbox" class="checkbox">. Form submission appends one FormData entry per selected value (matching native <select multiple> semantics). See the rendering-mode ADR.

Installation

pnpm add @neon-kit/theme @neon-kit/web-components

// In your bundle entry:
import '@neon-kit/theme/index.css';
import '@neon-kit/web-components/multicombobox';

Basic

Add selected to any number of <option> children to seed the initial selection. Toggling rows in the popover does not close it — press Escape or click outside when you're done.

Form participation

The element is form-associated. Submitting the form serialises every selected value as a separate entry under its name, just like <select multiple>. 


        

        
    


    

        
Filtering

        

            Open the popover and type to filter the list. Matching is a
            case-insensitive substring match against each option's text.
            Use ↑/↓ to
            move the highlight, Space or
            Enter to toggle.
        

        

            
                
                
                
                
                
                
                
                
                
                
                
                
                
                
                
            
        

    


    

        
Clearable

        

            Add data-clearable to render an inline
            "clear all" button next to the chevron. The button only
            shows when at least one value is selected; clicking it
            empties the selection and dispatches change.

Attributes

        

            

                
                    

                        Attribute
                        Description
                    

                
                
                    

                        name
                        Form field name. Each selected value is appended as a separate entry under this name.

                        Text shown in the field when no values are selected.

                        Disables the field and prevents the popover from opening.

                        Marks the field required for form validation. With no values, checkValidity() returns false.

                        Renders an inline clear-all button when at least one value is selected.

Accessibility pattern

        

            Implements the
            WAI-ARIA Combobox pattern
            with list autocomplete, manual selection, and a multi-select
            listbox (aria-multiselectable="true"). Focus
            stays on the search <input role="combobox">
            while open; the highlighted row is tracked with
            aria-activedescendant, leaving the user free
            to keep typing while navigating.
        


        
ARIA wiring

        
    
            
  • Field button: aria-haspopup="listbox", aria-expanded reflects the popover's open state, aria-required mirrors the host's required attribute.
    • 
            
  • Search input: role="combobox", aria-autocomplete="list", aria-expanded, aria-controls pointing at the listbox, aria-activedescendant pointing at the highlighted option row.
    • 
            
  • Listbox container: role="listbox" with aria-multiselectable="true".
    • 
            
  • Option rows: role="option" on each <label>; aria-selected mirrors the inner checkbox's checked state.
    • 
            
  • Each tag chip carries a .tag__remove button with an aria-label like "Remove United States".
    • 
        


        
Keyboard support

        

            

                
                    

                        Key
                        Action
                    

                
                
                    

                        
                            Enter /
                            Space /
                            ↓ /
                            ↑
                        
                        On the field: open the popover and focus the search input.
                    

                    

                        
                            ↓ /
                            ↑
                        
                        In the popover: move the active descendant through visible options, wrapping at the ends.
                    

                    

                        
                            Home /
                            End
                        
                        Jump the active descendant to the first / last visible option.
                    

                    

                        
                            Enter /
                            Space
                        
                        Toggle the active option. Popover stays open. Space is a no-op when the search input has text.
                    

                    

                        Escape
                        Close without changing selection, return focus to the field.
                    

                    

                        Tab
                        Close the popover and let the tab move on naturally.
