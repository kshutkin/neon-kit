Menu Component

A panel-styled list of focusable rows for dropdown menus, command palettes, and contextual actions. Items can carry icons (start or end), keyboard-shortcut hints, and chevrons for multi-level menus. Groups are visually divided and may have an optional header. RTL flips the layout automatically.

Inline

All variants together. Tab through the menu — only items receive focus; group headers and separators are skipped. Hover and :focus-visible produce the same highlight.

More actions

Dropdown (native popover)

Uses the native HTML Popover API plus CSS anchor positioning — no JavaScript. Click the trigger to open; press Esc or click outside to dismiss.

Preferred direction

Add one of the directional modifier classes to a popover-mode menu to change the side it opens on. Each modifier auto-flips to the opposite side(s) when the requested direction would overflow the viewport, so you only have to declare a preference — the browser handles edges. 

<div class="menu" popover>…</div>                  // default: drop down
<div class="menu -block-start" popover>…</div>     // drop up
<div class="menu -inline-end" popover>…</div>      // open right
<div class="menu -inline-start" popover>…</div>    // open left

RTL

Same markup, wrapped in dir="rtl". Start icons move to the right edge, the shortcut hint sits on the start (left) edge, and the chevron flips so the arrow always points toward the inline-end.
