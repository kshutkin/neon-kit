Tooltip — JSX

Tooltip is a @slimlib/jsx component that decorates one trigger element with the same popover-based Neon tooltip behavior as <neon-tooltip>. It returns the trigger element, appends the tooltip popover inside it, and keeps the tooltip in Light DOM.

Installation

pnpm add @neon-kit/theme @neon-kit/web-components @slimlib/jsx

import '@neon-kit/theme/index.css';
import { Tooltip } from '@neon-kit/jsx-components/tooltip';

Basic

Pass the trigger as the component child and the informational helper text as content. Default trigger is hover focus. 

<Tooltip content="Persists the current draft.">
    <button type="button" class="btn">Save</button>
</Tooltip>

Placement

Set placement to top, right, bottom, or left.

Rich Informational Content

content accepts JSX for non-interactive structure such as titles, body copy, icons, and keyboard shortcuts. Tooltips are informational helpers and must not contain links, buttons, inputs, or other interactive controls. 

<Tooltip
    placement="bottom"
    content={
        <>
            <div class="tooltip__title">Keyboard shortcut</div>
            <div class="tooltip__body">Open command search.</div>
            <div class="tooltip__meta">
                <span class="kbd-keys">
                    <kbd class="kbd">⌘</kbd>
                    <kbd class="kbd">K</kbd>
                </span>
            </div>
        </>
    }
>
    <button type="button" class="btn">Command search</button>
</Tooltip>

API

Prop Values Default Notes
children One HTMLElement Required The trigger element to decorate.
content JSX child content Required Informational, non-interactive tooltip body.
placement top | bottom | left | right top Adds a matching -<placement> class.
trigger Space-separated subset of hover focus click hover focus Use trigger="" to disable automatic triggers.

Accessibility Pattern

The generated popover receives role="tooltip" and the trigger receives aria-describedby unless it already has one. The component also wires anchor positioning so hover and focus opens place the popover against the trigger.

In development builds the component warns when the trigger child is invalid, when existing aria-describedby prevents the tooltip from wiring its own description, or when a focus tooltip is attached to a non-focusable trigger.
