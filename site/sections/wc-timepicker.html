Timepicker - Web Component

<neon-timepicker> is a shadow-DOM, form-associated custom element that wraps the theme's .timepicker markup with a typeable time field and popover list. It mirrors the native <input type="time"> API where practical, including value, min, max, step, required, readOnly, valueAsNumber, valueAsDate, stepUp(), stepDown(), and HTML form participation via ElementInternals. Values are HH:MM by default; add seconds to accept and display HH:MM:SS. See the rendering-mode ADR.

Installation

pnpm add @neon-kit/web-components
pnpm add -D @neon-kit/vite-plugin-style-build

// Configure styleBuild() in Vite (see Getting Started).
// In your bundle entry:
import '@neon-kit/web-components/timepicker';

Form participation

The element is form-associated. Submitting the form serialises the current time under its name, including an empty string when the field is blank, matching native input behavior. 


        

    


    

        
Seconds

        

            Add seconds when the value needs second precision.
            The value format switches to HH:MM:SS; step
            still uses native input semantics, so the number is measured in
            seconds.
        

        

            
        

    


    

        
Datalist Options

        

            Set list to a <datalist> id to use
            explicit suggestion rows instead of generated step rows. Invalid
            time values are ignored.
        

        

            
            
                
                
                
                
            
        

    


    

        
API


        
Attributes

        

            

                
                    

                        Attribute
                        Description
                    

                
                
                    

                        name
                        Form field name used when serialising the form.
                    

                    

                        value
                        Default value. Format is HH:MM, or HH:MM:SS when seconds is present.
                    

                    

                        min / max
                        Lower and upper time bounds used for constraint validation and generated list rows.
                    

                    

                        step
                        Native time step in seconds. Default is 60; use 900 for 15 minutes, or any to skip step validation.
                    

                    

                        list
                        Optional <datalist> id used for explicit popover suggestions.
                    

                    

                        placeholder
                        Text shown in the input. Defaults to HH:MM or HH:MM:SS.
                    

                    

                        disabled / readonly
                        Disable the field, or make it read-only while preserving form submission.
                    

                    

                        required
                        Marks the field required for constraint validation.
                    

                    

                        seconds
                        Boolean extension that enables HH:MM:SS values.
                    

                    

                        data-clearable
                        Renders an inline clear button when the field has text.
                    

                
            

        


        
Properties & methods

        

            

                
                    

                        Member
                        Type
                        Description
                    

                
                
                    

                        value
                        string
                        Current normalised value. Programmatic writes do not dispatch input or change.
                    

                    

                        defaultValue
                        string
                        Reflects the value attribute and is restored by form.reset().
                    

                    

                        valueAsNumber
                        number
                        Milliseconds since midnight, or NaN when empty.
                    

                    

                        valueAsDate
                        Date | null
                        A UTC 1970-01-01 date carrying the selected time.
                    

                    

                        stepUp() / stepDown()
                        (n?: number) => void
                        Move the value by n native time steps.
                    

                    

                        form / labels / validity / validationMessage / willValidate
                        -
                        Delegated to ElementInternals.
                    

                    

                        checkValidity() / reportValidity()
                        () => boolean
                        Standard form-validation methods.
                    

                
            

        


        
Events

        

            

                
                    

                        Event
                        When
                    

                
                
                    

                        input
                        User edits the text field, picks a row, or clears the value.
                    

                    

                        change
                        User commits a different value by leaving the field, picking a row, or clearing.
                    

                
            

        

    


    

        
Keyboard support

        

            

                
                    

                        Key
                        Action
                    

                
                
                    

                        ArrowDown / ArrowUp
                        Open the popover and move through suggested times.
                    

                    

                        Enter
                        When the popover is open, choose the active suggestion.
                    

                    

                        Escape
                        Close the popover without changing the value.
                    

                    

                        Tab
                        Commit typed text, close the popover, and continue tab navigation.
