Datepicker - Web Component

<neon-datepicker> is a Light-DOM, form-associated custom element that wraps the theme's .datepicker markup with a typeable date field and calendar popover. It mirrors the native <input type="date"> API where practical, including value, min, max, step, required, readOnly, valueAsNumber, valueAsDate, stepUp(), stepDown(), and HTML form participation via ElementInternals. Values use YYYY-MM-DD. See the rendering-mode ADR.

Installation

pnpm add @neon-kit/theme @neon-kit/web-components

// In your bundle entry:
import '@neon-kit/theme/index.css';
import '@neon-kit/web-components/datepicker';

Form participation

The element is form-associated. Submitting the form serialises the current date under its name, including an empty string when the field is blank, matching native input behavior. 


        

    


    

        
Calendar navigation

        

            The popover opens on the day grid. Use the header label to move
            to months and years, or the chevrons to page through the active
            view. Out-of-range days are disabled in the grid.
        

        

            
        

    


    

        
Step

        

            step uses native date-input semantics: the number is
            measured in days. With min="2026-01-01" and
            step="7", valid values fall on weekly intervals
            from the minimum date.
        

        

            
        

    


    

        
API


        
Attributes

        

            

                
                    

                        Attribute
                        Description
                    

                
                
                    

                        name
                        Form field name used when serialising the form.
                    

                    

                        value
                        Default value in YYYY-MM-DD format.
                    

                    

                        min / max
                        Lower and upper date bounds used for constraint validation and disabled calendar cells.
                    

                    

                        step
                        Native date step in days. Default is 1; use 7 for weekly intervals, or any to skip step validation.
                    

                    

                        placeholder
                        Text shown in the input. Defaults to YYYY-MM-DD.
                    

                    

                        disabled / readonly
                        Disable the field, or make it read-only while preserving form submission.
                    

                    

                        required
                        Marks the field required for constraint validation.
                    

                    

                        data-clearable
                        Renders an inline clear button when the field has text.
                    

                
            

        


        
Properties & methods

        

            

                
                    

                        Member
                        Type
                        Description
                    

                
                
                    

                        value
                        string
                        Current normalised value. Programmatic writes do not dispatch input or change.
                    

                    

                        defaultValue
                        string
                        Reflects the value attribute and is restored by form.reset().
                    

                    

                        valueAsNumber
                        number
                        Milliseconds at UTC midnight, or NaN when empty.
                    

                    

                        valueAsDate
                        Date | null
                        A UTC midnight Date for the selected calendar day.
                    

                    

                        stepUp() / stepDown()
                        (n?: number) => void
                        Move the value by n native date steps.
                    

                    

                        form / labels / validity / validationMessage / willValidate
                        -
                        Delegated to ElementInternals.
                    

                    

                        checkValidity() / reportValidity()
                        () => boolean
                        Standard form-validation methods.
                    

                
            

        


        
Events

        

            

                
                    

                        Event
                        When
                    

                
                
                    

                        input
                        User edits the text field, picks a day, or clears the value.
                    

                    

                        change
                        User commits a different value by leaving the field, picking a day, or clearing.
                    

                
            

        

    


    

        
Keyboard support

        

            

                
                    

                        Key
                        Action
                    

                
                
                    

                        ArrowDown
                        On the input, open the calendar.
                    

                    

                        Arrow keys
                        Inside a grid, move between date, month, or year cells.
                    

                    

                        Home / End
                        Move to the start or end of the current grid row.
                    

                    

                        Enter / Space
                        Activate the focused cell or navigation button.
                    

                    

                        Escape
                        Close the popover and return focus to the input.
                    

                    

                        Tab
                        Commit typed text, close the popover, and continue tab navigation.
