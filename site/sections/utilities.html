Utility Classes

Shared visual effects. Preview layout helpers belong to this site. The examples below use plain CSS properties for spacing, backgrounds, and effect colors.

metal-tinted

Applies a shiny, slightly worn brushed-metal finish on top of the element's own background color. Set any background-color color — the metal sheen tints to match.

Usage

<div class="metal-tinted" style="background-color: var(--neon-color-primary); border-radius: .5rem; padding: 1.5rem">
  Primary metal
</div>

The gradient and noise layers are applied via background-image and blend over the background-color, so background-color sets the tint automatically. Bevelled inset shadows complete the metal-plate look.

Without a --neon-glow-color custom property the glow uses currentColor, so text and glow are always the same hue. Add a --neon-glow-color custom property to paint the glow independently. The pulsing animation respects prefers-reduced-motion.

shadow-neon

Casts an asymmetric, pulsating neon glow underneath an element. Pair with any --neon-glow-color custom property to set the glow color independently from the text color. Falls back to currentColor when no shadow color is set.

shadow-neon shadow-neon-pink

shadow-neon shadow-neon-green

shadow-neon shadow-neon-yellow

shadow-neon shadow-neon-orange

shadow-neon shadow-neon-red

Usage

<button class="btn shadow-neon" style="--neon-glow-color: var(--neon-color-pink)">
  Pink glow
</button>

The glow uses var(--neon-glow-color, currentColor) so a --neon-glow-color custom property overrides the glow color without affecting text. The pulsing animation respects prefers-reduced-motion.

inset-shadow-neon

Mirror of shadow-neon, but the glow points inward — pooling along the inside edges of the element. Designed for form fields, inset panels, and any concave surface that should look lit from within. Pair with any --neon-glow-color custom property to set the glow color independently.

border-foil

Renders the element's border as a shifting iridescent foil ring with a sweeping glare — the foil effect applied to a border instead of a fill. Thickness is controlled by --neon-foil-border-width (defaults to 2px). The host does not need a CSS border-color declaration — the ring is drawn by a pseudo-element.

Usage

<div class="border-foil" style="--neon-foil-border-width: 4px; border-radius: .5rem; padding: 1rem">
  Thicker foil ring
</div>

<div class="border-foil shadow-neon" style="--neon-glow-color: var(--neon-color-pink); background-color: var(--neon-color-neutral)">
  Foil border and pink glow
</div>

The ring is painted by a ::before pseudo-element using the mask-composite "donut" technique — the inner content-box is subtracted from the full box, leaving a clean rounded ring (something border-image can't do without squaring the corners). The host's background-color and any box-shadow remain untouched, so it composes cleanly with shadow-neon, foil, and background-color properties. The shimmer animation respects prefers-reduced-motion.
