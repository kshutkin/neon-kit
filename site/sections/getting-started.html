Getting Started

Neon Kit ships a Tailwind-based theme package and optional native web components. Import the theme stylesheet once in your app entry, then use the component classes in your markup.

Install the theme

pnpm add @neon-kit/theme

// In your bundle entry:
import '@neon-kit/theme/index.css';

Use the CSS components

Theme components are plain CSS classes, so they work with native elements and your framework's regular templates. 

<button class="btn cta">Save changes</button>

Add web components

Install the web component package when you want the native custom elements to manage interaction, keyboard behavior, and form participation for supported controls. 

pnpm add @neon-kit/theme @neon-kit/web-components

// In your bundle entry:
import '@neon-kit/theme/index.css';
import '@neon-kit/web-components/tooltip';

Web components render in Light DOM and do not attach shadow roots. The host page must include @neon-kit/theme/index.css or a theme-equivalent stylesheet for them to render correctly.
