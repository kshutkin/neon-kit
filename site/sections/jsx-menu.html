Menu — JSX

Menu decorates one button trigger and renders a sibling native popover containing MenuItem buttons. It shares the same roving focus, keyboard navigation, nested-menu coordination, and accessible labelling behavior as <neon-menu>.

Installation

pnpm add @neon-kit/theme @neon-kit/jsx-components @slimlib/jsx

import '@neon-kit/theme/index.css';
import { Menu, MenuItem } from '@neon-kit/jsx-components/menu';

Basic

Pass one button as the trigger and menu JSX as content. The component wires IDs, popovertarget, menu roles, and labelling automatically. 

<Menu
    content={
        <div class="menu__group">
            <MenuItem onClick={createFile}>New file</MenuItem>
            <MenuItem>Open</MenuItem>
            <MenuItem disabled>Delete</MenuItem>
        </div>
    }
>
    <button type="button" class="btn">Actions</button>
</Menu>

Nested menus

Use a MenuItem as another Menu's trigger. → opens the submenu, ← returns to its parent item, and activating a leaf closes the complete open menu tree.

API

  • Menu.children: exactly one HTMLButtonElement trigger.
  • Menu.content: JSX containing owned MenuItem descendants.
  • Menu.placement: block-end, block-start, inline-end, or inline-start.
  • MenuItem.disabled: creates focusable aria-disabled="true" state and suppresses activation.
  • MenuItem.onClick: runs for enabled item activation before leaf menus close.
