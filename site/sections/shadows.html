Shadow Tokens Showcase

Composable slot-based shadows using Tailwind v4. inset-shadow-* sets --tw-inset-shadow and shadow-* sets --tw-shadow. Both slots are merged into a single box-shadow declaration automatically, so you can combine one of each to build composite effects.

Inset Shadow Tokens

These tokens use the inset-shadow-* utility and populate the --tw-inset-shadow slot.

Highlight

inset-shadow-highlight

--inset-shadow-highlight

Neutral top-edge highlight for surfaces and buttons

Primary Highlight

inset-shadow-highlight-pressed

--inset-shadow-highlight-pressed

Primary-tinted top-edge highlight for CTA buttons

Pressed

inset-shadow-pressed

--inset-shadow-pressed

Depressed/pressed inset shadow for active states

Outer Shadow Tokens

These tokens use the shadow-* utility and populate the --tw-shadow slot.

Drop

shadow-drop

--shadow-drop

Standard 2px blur drop shadow for elevation

Drop Subtle

shadow-drop-subtle

--shadow-drop-subtle

Lighter 1px blur drop shadow for hover states

Focus Ring

shadow-focus-ring

--shadow-focus-ring

2px focus ring for accessibility

Composition Examples

Combine one inset-shadow-* token with one shadow-* token on the same element. Tailwind v4 merges them into a single box-shadow declaration.

Elevated

Elevated = highlight + drop

inset-shadow-highlight shadow-drop

Default button/card look — inset highlight for top shine combined with a standard drop shadow for depth

Subtle

Subtle = highlight + drop-subtle

inset-shadow-highlight shadow-drop-subtle

Very light elevation — inset highlight with a soft, minimal drop shadow

Flat Focus

Flat Focus = focus-ring alone

shadow-focus-ring

Focus ring on a flat element with no inset shadow

Elevated Focus

Elevated Focus = highlight + focus-ring

inset-shadow-highlight shadow-focus-ring

Focused elevated element — inset highlight paired with a focus ring for accessible interactive states
