Badges

The .badge component renders a compact pill label for counts, statuses, or categories. It shares the visual family of .kbd (rounded, bordered, top-edge highlight) but is pill-shaped, sized in em, and ships with semantic modifiers built from the theme's state tokens.

Variants

Default is the neutral surface; .-primary mirrors the filled .btn.cta look. The four state modifiers — .-success, .-warning, .-error, .-info — use translucent tints from the matching theme tokens with full-strength borders.

Counts

Single-character contents render as a circle thanks to the shared min-inline-size = block-size rule; multi-digit counts grow inline.
