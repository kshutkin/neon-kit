Icon - Web Component

  • Library
  • Web Component

<neon-icon> is a Light-DOM custom element that renders @neon-kit/icons definitions as inline SVG. Use it when authoring HTML directly or when a component boundary makes a custom element more convenient than importing and placing SVG yourself. For package-only usage, see the Icons library.

Installation

pnpm add @neon-kit/icons @neon-kit/web-components

// Side-effect register the <neon-icon> element.
import '@neon-kit/web-components/icon';

Name loading

Set name to <variant>/<icon>, matching the icon package subpath layout. The element dynamic-imports the requested module and renders into Light DOM so it inherits currentColor. 

<neon-icon name="outline/bars-3"></neon-icon>
<neon-icon name="solid/check" label="Confirmed"></neon-icon>
outline/bars-3 solid/check mini/x-mark micro/chevron-down

Property override

For maximum tree-shaking, statically import an icon definition and assign it to the icon property. That path skips dynamic loading and takes precedence over name until cleared. 

import bars from '@neon-kit/icons/outline/bars-3';

const el = document.querySelector('neon-icon');
el.icon = bars;            // synchronous render; wins over `name`
el.icon = undefined;       // clear; falls back to `name` loading

Sizing & color

The rendered SVG uses width="1em" and height="1em", so set font-size on the host or an ancestor. Icon color follows currentColor.

API

Member Type Description
name string Attribute/property in <variant>/<icon> form, such as outline/bars-3.
icon IconDef | undefined Property-only override. Assign an imported icon definition for synchronous rendering; set to undefined to resume name loading.
label string Attribute/property label for meaningful icons. Sets the host element's ElementInternals accessible name and default role="img".

Accessibility

Without a label, icons render as decorative content hidden by default through ElementInternals. For a meaningful icon, set the label attribute or property. Raw ARIA attributes are also supported, but host aria-label must be paired with role="img". Add a label only when the icon itself carries information that is not already present in nearby text. 

<button class="btn">
    <neon-icon name="outline/trash"></neon-icon>
    Delete
</button>

<button class="btn" aria-label="Delete">
    <neon-icon name="outline/trash"></neon-icon>
</button>

<neon-icon name="solid/check" label="Confirmed">
</neon-icon>

<neon-icon name="solid/check" role="img" aria-label="Confirmed">
</neon-icon>

<script>
    document.querySelector('neon-icon').label = 'Confirmed';
</script>
