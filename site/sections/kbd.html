Keyboard Shortcuts

The .kbd component renders a keyboard shortcut as a small, flat nameplate. It shares the visual family of .btn (rounded, bordered, top-edge highlight) but is non-interactive and intentionally flatter — no drop shadow, slightly muted surface, tighter proportions, monospaced glyphs.

Single Keys

Square-by-default sign proportions. Single-character keys — letters, digits, and platform glyphs (⌘ ⌥ ⌃ ⇧ ⏎ ⌫ ⎋ ⇥) — render as identical squares regardless of glyph width.

A K 7 ⌘ ⇧ ⌥ ⌃ ⏎ ⌫ ⎋ ⇥ ↑ ↓ ← →

Multi-character Labels

Word labels keep the same height and stretch horizontally with even side padding.

Esc Tab Ctrl Shift Alt Enter Space Backspace F12 Page Up

Combos

Wrap individual keys in .kbd-keys for consistent heights and equal visual gaps. Use .kbd-keys__sep for an explicit textual separator (e.g. +) when the convention calls for it.

⌘ K ⌘ ⇧ P ⌃ ⌥ ⌫ Ctrl + Shift + N Alt + F4

Inline With Prose

Keys sit on the surrounding text baseline and inherit font-size, so they scale naturally inside paragraphs and headings.

Press ⌘, to open preferences, or hit ⌘⇧P for the command palette.

Smaller text — Esc dismisses the dialog. The keys scale with the line.

Larger text — ⌘F opens find. Heights still match.

In a Menu

Drop the .kbd nameplate into a menu row in place of the default .menu__shortcut label when you want a heavier, more legend-like trailing affordance.
