About Neon Kit

Neon Kit is a Tailwind-based theme paired with optional Light-DOM web components. The theme provides the visual language; the web components add native interaction, keyboard behavior, and form participation for the controls that benefit from it.

What's inside

  • @neon-kit/theme — Tailwind theme tokens and component CSS.
  • @neon-kit/web-components — Light-DOM custom elements that consume the theme.

Project goals

  • Minimal runtime — ship raw CSS and unbundled JS.
  • Lean on native browser features: popover API, anchor positioning, ElementInternals.
  • No bundler lock-in — drop into any toolchain that handles ESM and CSS.
