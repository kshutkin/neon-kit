About Neon Kit

Neon Kit is a CSS Modules theme with a plain CSS entry paired with optional shadow-DOM web components. The theme provides the visual language; the web components add native interaction, keyboard behavior, and form participation for the controls that benefit from it.

What's inside

  • @neon-kit/theme-vanilla — complete CSS for classical HTML.
  • @neon-kit/theme — shared CSS Modules, tokens, resets, and effects.
  • @neon-kit/web-components — shadow-DOM custom elements that consume the theme.

Project goals

  • Minimal runtime — ship raw CSS and unbundled JS.
  • Lean on native browser features: popover API, anchor positioning, ElementInternals.
  • No bundler lock-in — drop into any toolchain that handles ESM and CSS.
