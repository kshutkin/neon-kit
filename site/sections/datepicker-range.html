Datepicker — Range

A range-selection variant of .datepicker. Same field chrome, same single overlay — the only differences live on the day cells. The user picks the first endpoint, navigates to bring the second one into view if needed (next month / year / decade via the existing header), then picks the second endpoint. While the second pick is pending, the wrapper carries .-range-pending and the band follows the cursor as a tentative preview; once committed, the band is rendered from the stored start/end pair.

Plain

data-range on the wrapper switches the picker into range mode. The field shows YYYY-MM-DD / YYYY-MM-DD once both endpoints have been picked.

Pre-filled with Clear

data-value="YYYY-MM-DD/YYYY-MM-DD" seeds an initial range. data-clearable shows a clear button — clicking it wipes both endpoints and resets the wrapper out of pending state.

Static Views

Two day-grid snapshots side-by-side: the left panel shows a committed range (.-range-start, .-in-range, .-range-end); the right one shows the same cells under .-range-pending — the trailing endpoint switches to a dashed outline and the band fill softens so the user can read the preview as tentative.
