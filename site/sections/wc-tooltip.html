Tooltip — Web Component

<neon-tooltip> is an autonomous custom element. Drop it inside the element you want to annotate; it turns its own markup into a popover styled by @neon-kit/theme and wires the parent as the trigger. Renders Light DOM only — see the rendering-mode ADR.

Installation

pnpm add @neon-kit/theme @neon-kit/web-components

// In your bundle entry:
import '@neon-kit/theme/index.css';
import '@neon-kit/web-components/tooltip';

Basic

Plain text inside the element becomes the tooltip body. Default trigger is hover focus; on a <button> parent you also get free click-to-toggle from the platform.

Placement

Set data-placement to one of top (default), right, bottom, or left.

Rich content

Put any markup inside. Structural content disables the implicit role="tooltip" (use the popover semantics instead).

Non-button parents

Works on any focusable element. Void elements (<input>, <img>) cannot host children — wrap them.

Focus meTooltips work on links too. Focusable span Add tabindex="0" to make a non-focusable element keyboard-reachable.
