Tags

The .tag component is a labelled chip with a built-in remove button. It shares the visual family of .badge (rounded, bordered, top-edge highlight, em-sized) but with squarer corners that seat well alongside form controls and a trailing .tag__remove close affordance.

Variants

Same modifier set as .badge: default neutral surface, .-primary filled, plus state tints (.-success, .-warning, .-error, .-info).

Default Primary Success Warning Error Info

Tag List

The optional .tag-list wrapper provides a flex row with consistent em-sized gaps so a list of chips wraps cleanly inside any container.

In a Form Field

Pair tags with an .input to build a token-style multi-select. The input's inset-pressed shadow doubles as the container affordance.
