Combobox — Web Component

<neon-combobox> is a Light-DOM, form-associated custom element that wraps the theme's .combobox markup with a single-select, filterable, keyboard-friendly popover. List options as plain <option> children — the element synthesises the field, popover, search input, and option rows for you, and participates in HTML forms via ElementInternals. See the rendering-mode ADR.

Installation

pnpm add @neon-kit/theme @neon-kit/web-components

// In your bundle entry:
import '@neon-kit/theme/index.css';
import '@neon-kit/web-components/combobox';

Form participation

The element is form-associated. Submitting the form serialises the current selection under its name. The demo captures the submitted FormData below. 


        

        
    


    

        
Filtering

        

            Open the popover and type to filter the list. Matching is a
            case-insensitive substring match against each option's text.
            Use ↑/↓ to move
            the highlight, Enter to select.
        

        

            
                
                
                
                
                
                
                
                
                
                
                
                
                
                
                
            
        

    


    

        
Clearable

        

            Add data-clearable to render an inline clear
            button next to the value. The button only shows when a value
            is set; clicking it clears the selection and dispatches
            change.
        

        

            
                
                
                
                
                
                
                
                
            
        

    


    

        
API


        
Attributes

        

            

                
                    

                        Attribute
                        Description
                    

                
                
                    

                        name
                        Form field name used when serialising the form.
                    

                    

                        value
                        Currently selected option value. Setting an unknown value is a no-op (matches native <select>).
                    

                    

                        placeholder
                        Text shown when no value is selected.
                    

                    

                        disabled
                        Disables the field and prevents the popover from opening.
                    

                    

                        required
                        Marks the field required for form validation. With no value set, checkValidity() returns false.
                    

                    

                        data-clearable
                        Renders an inline clear button when a value is set.

Accessibility pattern

        

            Implements the
            WAI-ARIA Combobox pattern
            with list autocomplete and manual selection. Focus stays on
            the search <input role="combobox">; the
            highlighted option is tracked with
            aria-activedescendant rather than DOM focus, so
            the user can keep typing while navigating the list.
        


        
ARIA wiring

        
    
            
  • Search input: role="combobox", aria-autocomplete="list", aria-expanded, aria-controls pointing at the listbox, aria-activedescendant pointing at the highlighted option row.
    • 
            
  • Listbox container: role="listbox" on the popover's option list.
    • 
            
  • Option rows: role="option" with aria-selected="true" on the chosen one.
    • 
            
  • Field button: aria-haspopup="listbox", aria-expanded reflects the popover's open state, aria-required mirrors the host's required attribute.
    • 
        


        
Keyboard support

        

            

                
                    

                        Key
                        Action
                    

                
                
                    

                        
                            Enter /
                            Space /
                            ↓
                        
                        On the field: open the popover and focus the search input.
                    

                    

                        
                            ↓ /
                            ↑
                        
                        In the popover: move the active descendant through visible options, wrapping at the ends.
                    

                    

                        
                            Home /
                            End
                        
                        Jump the active descendant to the first / last visible option.
                    

                    

                        Enter
                        Select the active option, close the popover, return focus to the field.
                    

                    

                        Escape
                        Close without changing selection, return focus to the field.
                    

                    

                        Tab
                        Close the popover and let the tab move on naturally.
