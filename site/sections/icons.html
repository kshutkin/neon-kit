Icons

@neon-kit/icons is a curated set of heroicon-derived SVG icons. Each heroicon ships in four variants — outline (24×24 stroked, 1.5px), solid (24×24 filled), mini (20×20 filled), and micro (16×16 filled). Pick a variant via the subpath segment: @neon-kit/icons/outline/bars-3, @neon-kit/icons/solid/bars-3, etc. Each icon is its own ESM module so bundlers tree-shake unused ones.

Variant comparison

The same icon at each variant's native pixel box. Outline and solid share a 24×24 viewBox; mini renders at 20×20; micro at 16×16. Pick the smallest variant that still reads at the size you intend to render.

Subpath ESM usage

Preferred for tree-shaking. Each variant lives under its own segment; each icon module exports a default { viewBox, attrs, paths } definition and a precomputed svg string. 

import outlineMenu from '@neon-kit/icons/outline/bars-3';   // 24×24, stroke 1.5
import solidMenu from '@neon-kit/icons/solid/bars-3';       // 24×24, filled
import miniMenu from '@neon-kit/icons/mini/bars-3';         // 20×20, filled
import microMenu from '@neon-kit/icons/micro/bars-3';       // 16×16, filled
// outlineMenu: { viewBox, attrs, paths }
// import { svg } from '@neon-kit/icons/outline/bars-3' for the precomputed string

Aggregate ESM usage

Convenient when you need many icons in one place; pulls the entire variant into the module graph. 

import { outline, solid, mini, micro } from '@neon-kit/icons';
const menu = outline['bars-3'];
const menuSolid = solid['bars-3'];

// or import a single variant aggregate:
import outlineIcons from '@neon-kit/icons/outline';
outlineIcons['bars-3'];

<neon-icon> element

The icon data lives in @neon-kit/icons and the <neon-icon> element lives in @neon-kit/web-components. Set the name attribute to <variant>/<icon> (matching the package subpath layout) and the element dynamic-imports the icon on demand. Repeated requests for the same name share a single import. The element renders into Light DOM and inherits currentColor from its host context. 

// Side-effect register the <neon-icon> element.
import '@neon-kit/web-components/icon';
<neon-icon name="outline/bars-3"></neon-icon>
<neon-icon name="solid/x-mark" size="24" aria-label="Close"></neon-icon>

For maximum tree-shaking, statically import the icon and assign it to the icon property — that path skips the dynamic import and gives your bundler an exact module reference to analyze. 

import bars from '@neon-kit/icons/outline/bars-3';

const el = document.querySelector('neon-icon');
el.icon = bars;            // synchronous render; takes precedence over `name`
el.icon = null;            // clear; falls back to `name`-based loading

Sizing & color

The SVG inherits currentColor, so any Tailwind text-color utility colors the icon. Use size for a numeric (px) or any CSS length (e.g. 1.5rem).
