Combobox — Single-Select

Single-select .combobox — a focusable field that opens a .menu-styled popover with one selectable option. The field reuses the inset-well language of .input; the popover reuses the panel chrome of .menu. A trailing clear button removes the current value, an optional search field filters options, and an optional "Create new" row appends an option from the typed query. Layout is logical-property based so the control flips cleanly under dir="rtl".

Plain

The minimum: a field, a chevron, and a list of options. Click the field or press Space / Enter while focused to toggle the popover.

With Clear

Adding a .combobox__clear button next to the value lets users remove the current selection without opening the popover.

With Search

A sticky .combobox__search header at the top of the popover filters the list as the user types. Empty-state row appears when the filter eliminates every option.

With Create New

data-creatable opts in to a footer row that lets users add a new option from the typed query. The footer row only appears while the query is non-empty and not already in the list.

Disabled

A disabled field uses the same muted-surface treatment as .input:disabled and .btn:disabled.

RTL

Setting dir="rtl" on any ancestor flips the field, the chevron position, and the popover anchor side — no per-component code required.
