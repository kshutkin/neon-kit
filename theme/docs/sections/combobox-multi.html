Combobox — Multi-Select

Multi-select .combobox.-multi — same field/popover family as the single-select variant, but the field hosts a wrappable tag list and an inline auto-growing search input that expand the field's block size as more items are picked. Each tag carries its own .tag__remove close affordance, the popover uses .checkbox-prefixed option rows, and footer slots can host an optional "Select all" toggle and an optional "Create new …" row. RTL is handled by the same logical-property layout that single-select uses.

Plain

Click the field or focus it and press Space to open. Click options to toggle them; click a tag's × to remove it.

With Search and Select All

data-searchable mounts a sticky search header; data-select-all mounts a "Select all" toggle in the popover footer. The toggle reflects an indeterminate state when only some options are selected.

With Create New

data-creatable appends a "Create new" footer row when the search query doesn't match any existing option. Pressing Enter in the inline field also creates a tag if creation is enabled.

Everything On

Search, select-all, and create-new together. Add a few tags and watch the field grow vertically as the tag list wraps; the trailing chevron stays parked at the inline-end edge.

RTL

Tags wrap inline-start to inline-end; the chevron parks at the inline-end (visually left in RTL); the popover anchors from the field's bottom-start edge.
