Timepicker

A typeable time field paired with a popover list of time points rendered at a configurable step (15 / 30 / 60 minutes are common). The field reuses .input's inset-well chrome and the trailing-control language of .combobox / .datepicker; the popover reuses .combobox__popover panel chrome with .combobox__option rows. Optional features: data-step changes the increment, data-seconds adds :SS to the format, and data-tz mounts an IANA timezone selector inside the popover. A combined date + time popover places the day grid and time list side by side (stacked under 640px).

Plain (30-minute step)

Default: a typeable HH:MM input with a clock trigger. The popover lists every half hour from 00:00 to 23:30; click a row to commit and close.

15-Minute Step + Clear

data-step="15" packs the list at quarter-hour granularity. The clear button hides until the field has a value.

With Seconds (1-Hour Step)

data-seconds formats values as HH:MM:SS; data-step="60" shows a shorter list of hourly options.

With Timezone

data-tz renders an inline IANA-zone button next to the time. Clicking it opens a *separate* popover with the same chrome as a single-select .combobox — search at the top, options below, click to commit. The field's zone hint updates live, so a committed time always reads in context without leaving the control.

Field States

Same six-state vocabulary as the datepicker. State hooks land on the inner .timepicker__input; the .timepicker__field wrapper reacts via :has(). Only the field appearance is shown — the time-list popover is unchanged.

Combined Date + Time

.datetime-picker wraps a date and a time field side by side so users can pick both with a single trigger. The shared popover is a .datepicker__popover.-with-time: the day grid sits inline-start, the time list inline-end. On viewports under 640px the panels stack vertically and the popover narrows to fit.

RTL

Logical-property layout flips field order, the trailing trigger, and the combined date+time panel order under dir="rtl".
