Utility Classes

Custom utility classes that extend the design system.

metal-tinted

Applies a shiny, slightly worn brushed-metal finish on top of the element's own background color. Set any bg-* color — the metal sheen tints to match.

Neutral metal

metal-tinted bg-neutral

Primary metal

metal-tinted bg-primary

Neon blue

metal-tinted bg-neon-blue

Neon pink

metal-tinted bg-neon-pink

Neon green

metal-tinted bg-neon-green

Gunmetal dark

metal-tinted bg-neutral-dark

Usage

<!-- Any bg-* color works as the tint base -->
<div class="metal-tinted bg-primary rounded-lg p-6">
  Primary chrome
</div>

<div class="metal-tinted bg-neon-pink rounded-lg p-6">
  Pink chrome
</div>

The gradient and noise layers are applied via background-image and blend over the background-color, so any color utility sets the tint automatically. Bevelled inset shadows complete the metal-plate look.

text-neon

Applies a pulsating luminous neon glow to text. By default the glow color follows the text-* color. Add a shadow-* utility to decouple the glow color from the text color.

Pink glow, green text

text-neon shadow-neon-pink text-neon-green

Usage

<!-- Glow follows text color -->
<span class="text-neon text-neon-blue">Glowing Blue</span>

<!-- Decouple glow from text color with shadow-* -->
<span class="text-neon shadow-neon-pink text-neon-green">
  Pink glow, green text
</span>

Without a shadow-* utility the glow uses currentColor, so text and glow are always the same hue. Add a shadow-neon-* utility to paint the glow independently. The pulsing animation respects prefers-reduced-motion.

shadow-neon

Casts an asymmetric, pulsating neon glow underneath an element. Pair with any shadow-* color utility to set the glow color independently from the text color. Falls back to currentColor when no shadow color is set.

shadow-neon shadow-neon-blue

shadow-neon shadow-neon-pink

shadow-neon shadow-neon-green

shadow-neon shadow-neon-yellow

shadow-neon shadow-neon-orange

shadow-neon shadow-neon-red

Usage

<!-- shadow-* sets the glow color independently from text color -->
<button class="shadow-neon shadow-neon-pink text-white">
  Pink glow, white text
</button>

<!-- Without shadow-*, falls back to currentColor -->
<button class="shadow-neon text-neon-blue">
  Blue glow from text color
</button>

The glow uses var(--tw-shadow-color, currentColor) so a shadow-* color utility overrides the glow color without affecting text. The pulsing animation respects prefers-reduced-motion.

<!-- Tube only — border-* sets the tube color -->
<div class="border-neon border-neon-blue border-2 rounded-lg">
  Blue tube
</div>

<!-- Tube + outward cast glow: border-* for tube, shadow-* for glow -->
<div class="border-neon shadow-neon border-neon-pink shadow-neon-pink border-2 rounded-lg">
  Pink tube with glow
</div>

<!-- Mixed: tube and glow in different colors -->
<div class="border-neon shadow-neon border-neon-green shadow-neon-blue border-2 rounded-lg">
  Green tube, blue glow
</div>

The tube color uses var(--tw-border-color, currentColor), so any border-* utility sets the tube fill automatically. Combine with shadow-neon and a shadow-* color to add a directional outward glow independently from the tube color.
