Navigation Component

Element-agnostic interactive rows for sidebar navigation, horizontal tabs, and radio-input segmented controls. Selectors target .nav__item, so the same styles work on <a>, <button>, <label>, <li>, or <div> — choose the most semantic element for each use-case. Active state is opt-in via the .-active modifier; ARIA hooks like aria-current and aria-selected are author concerns and are styled independently.

Sidebar (vertical)

Flat surface — no panel elevation. Best as a section landmark with <nav> wrapping a <ul> of links. The active row carries both .-active (visuals) and aria-current="page" (semantics).

Sidebar on plain <div> rows

Selectors don't depend on element type — but plain <div>s aren't focusable or activatable. Prefer <a> or <button> for any clickable nav. This is shown only to illustrate the styles attach to the class.

Tabs (horizontal, elevated active)

The tab bar sits on a recessed track; the active tab raises into a panel and merges with the content below. Use <button role="tab"> for in-page tab switching with aria-selected, paired with .-active for visuals.

Segmented control (radio-backed)

A recessed track with a raised "thumb" on the checked option. Backed by a real <fieldset> of <input type="radio">s so it submits with forms and works without JavaScript. The checked input's visual focus ring is mirrored onto the visible <label>.
