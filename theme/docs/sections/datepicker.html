Datepicker

A typeable date field paired with a popover that hosts three navigable views — days inside a month, months inside a year, and years inside a decade. The field reuses the inset-well chrome of .input and the trailing-control language of .combobox: a clear button (optional) plus a calendar-icon trigger. Each cell in every view is a focusable button so the picker is fully keyboard-navigable. Layout is logical-property based; everything flips cleanly under dir="rtl".

Plain

The minimum: a typeable input and a calendar trigger that opens the day grid. Click the header label to step up to the month view, then again to the year view.

With Clear

Adding data-clearable shows a clear button when the field has a value — same affordance language as .combobox__clear.

Disabled

A disabled <input> applies the same muted-surface treatment as .input:disabled and .btn:disabled across the whole field.

Static Views

Each of the three overlays rendered inline so the layout is visible without opening a popover. Each cell is a real <button>; tab through to confirm keyboard reachability.

RTL

Setting dir="rtl" on any ancestor flips the field, the trailing trigger, the prev/next chevrons, and the popover anchor side — no per-component code required.
