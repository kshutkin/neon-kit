Form Controls

Inputs, checkboxes, radios, and fieldsets share the visual family of .btn: same border, same focus ring, same disabled treatment. Inputs read as an inset well (you type into them) while checkboxes and radios re-use the raised .btn shape and fill with --color-primary when checked. Fieldsets are flat frames — no drop shadow — that group related fields under a small-caps legend.

Text Inputs

Apply .input to any single-line form control. Layout (width, stretch) is owned by the surrounding container — the component sets only the chrome.

Input Types

.input works on every native text-like control — email, number, search, date, file, plus <textarea> and <select>. The chevron on a styled <select> is rendered via background-image so it's consistent across browsers.

Checkboxes

Native <input type="checkbox"> with the UA chrome stripped and re-rendered as a small .btn-shaped square. Sized in em so the box tracks its label's font-size automatically.

Radio Buttons

Same shape as .checkbox but circular and with a dot instead of a tick. Group radios with a shared name in the usual native way.

Fieldset

.fieldset is a flat frame for grouping related fields. Pair it with native <legend> for an accessible group label that browsers expose to assistive tech.
