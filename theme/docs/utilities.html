Utility Classes

Custom utility classes that extend the design system.

metal-tinted

Applies a shiny, slightly worn brushed-metal finish on top of the element's own background color. Set any bg-* color — the metal sheen tints to match.

Neutral metal

metal-tinted bg-neutral

Primary metal

metal-tinted bg-primary

Neon blue

metal-tinted bg-neon-blue

Neon pink

metal-tinted bg-neon-pink

Neon green

metal-tinted bg-neon-green

Gunmetal dark

metal-tinted bg-neutral-dark

Usage

<!-- Any bg-* color works as the tint base -->
<div class="metal-tinted bg-primary rounded-lg p-6">
  Primary chrome
</div>

<div class="metal-tinted bg-neon-pink rounded-lg p-6">
  Pink chrome
</div>

The gradient and noise layers are applied via background-image and blend over the background-color, so any color utility sets the tint automatically. Bevelled inset shadows complete the metal-plate look.
